Factory Inventory Management System

Full-stack demo: Vue 3 single-page app, Python FastAPI backend, and in-memory data loaded from JSON files. There is no database.

Data flow

What happens when a user changes a filter on any page.

  1. User changes a filter FilterBar → shared refs in composables/useFilters.js
    Four filters (period, warehouse, category, status) live in module-level refs, so every view sees the same state.
  2. View reacts and requests data Views in client/src/views/*.vue
    A watch fires, the view calls getCurrentFilters() and passes the result to api.*. Period is sent as month.
  3. API client builds the query client/src/api.js
    Filters set to all are skipped. Axios sends GET http://localhost:8001/api/...?warehouse=&category=&status=&month=.
  4. FastAPI routes the request server/main.py
    The handler filters the in-memory list with apply_filters and filter_by_month. Month accepts YYYY-MM or a quarter such as Q3-2025.
  5. Data comes from memory server/mock_data.py ← server/data/*.json
    JSON files are read once at startup into Python lists. Handlers never write to them.
  6. Response is validated and returned Pydantic response_model
    List endpoints return typed models. Dashboard summary and report endpoints return computed dicts.
  7. UI re-renders View refs → computed properties
    Raw responses are stored in refs (for example allOrders, inventoryItems). Charts, KPIs and tables derive from computed properties.

Things to know

Observed in the code today.

Client calls endpoints the server does not define. api.js has getTasks, createTask, deleteTask, toggleTask, createPurchaseOrder and getPurchaseOrderByBacklogItem. main.py has no /api/tasks or /api/purchase-orders routes, and defines CreatePurchaseOrderRequest without using it. Those calls would return 404.
Month filter does not apply to every dataset. Inventory has no date field, so inventory requests ignore the period filter. Orders are filtered on order_date.
Read-only, demo-grade server. No authentication, CORS open to all origins, no persistence, and the API base URL is hard-coded in api.js.
Report quarters are hard-coded to 2025. /api/reports/quarterly and QUARTER_MAP only recognise 2025 months.
